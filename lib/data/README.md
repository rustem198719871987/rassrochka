# Справочники

`fms_unit.csv.gz` — коды подразделений, выдающих паспорта, и их названия («кем выдан»).
Источник: [hflabs/fms-unit](https://github.com/hflabs/fms-unit), составитель DaData.ru, данные от 22.10.2026.
Лицензия данных: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Обновить: скачать свежий `fms_unit.csv` из репозитория и выполнить `gzip -9 -c fms_unit.csv > lib/data/fms_unit.csv.gz`.
